# Evaluation Criteria for modern-python

## Correctness
- Does the skill successfully complete its primary objective?
- Are the outputs correctly formatted according to the guidelines?

## Robustness
- Does the skill handle edge cases gracefully?
- Is the error handling clear and helpful?

## Efficiency
- Does the workflow minimize unnecessary steps or tool calls?
- Is progressive disclosure effectively used (i.e. not overloading context)?
